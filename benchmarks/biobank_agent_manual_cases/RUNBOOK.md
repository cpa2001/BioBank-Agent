# Manual Execution Runbook

这个 runbook 是人工测试的固定流程。除非 case 特别说明，不要为了让测试通过而修改输入；如果 agent 卡住、误解或暂停，记录下来，这本身就是测试结果。

## 1. 启动前记录

```bash
cd /Users/chenpengan/Projects/CUHK/UKB_agent
git status --short
python -m biobank_agent.cli
```

CLI 启动面板会显示常用环境信息。需要额外诊断时再运行 `/status`、`/skills` 或 `/external-agents`。

记录：

- 当前模型。
- skills 总数。
- Codex/Claude external agents 是否 available。
- 数据目录是否指向真实 UKB parquet/catalog。

## 2. 执行单个 case

每个 case 都包含一个 `Main prompt`。推荐流程：

```text
/plan <Main prompt>
```

在 review 阶段检查计划：

- 是否包含 case 要求的关键 skills。
- `generate_report` 是否为 `format="dual"`。
- `generate_report` 前是否有 `statistical_review`、`safety_check`、`world_model_audit`。
- 模型任务是否包含 `cohort_summary -> missing_data -> train_model(model_type="auto") -> evaluate_model -> calibration -> feature_importance`。
- trajectory 任务是否包含 `cohort_card`、`trajectory_tokenize`、`world_model_audit`，并准备 fallback model。
- plan step args 是否符合真实 schema。

如果计划缺关键步骤，直接用自然语言 feedback：

```text
Add missing_data, train_model(model_type="auto"), evaluate_model, calibration, feature_importance, world_model_audit, and a dual report. Keep all args schema-valid.
```

然后：

```text
/plan-approve
```

执行完成后如果 CLI 弹出 review hook 选项，选 `A` 会启动 Codex + Claude 审核；选 `N` 跳过。`/status` 和 `/plans` 只在你需要排查状态或查找历史 plan 时使用。

## 3. 报告检查

找到最新报告目录：

```bash
ls -td reports/* | head -5
```

检查完整 artifacts：

```bash
ls -1 reports/<timestamp>
```

检查报告内容：

```bash
rg -n "Abstract|Methods|Results|Discussion|Model Selection|Limitations|Governance|Data availability|not causal" reports/<timestamp>/report_technical.md reports/<timestamp>/report_nature.md
rg -n "Generated by|Codex|Claude|OpenAI|TODO|CITATION_NEEDED|Traceback|unexpected keyword" reports/<timestamp>
```

任何命中第二条命令都要人工判断，通常是扣分或 fail。

## 4. 评分

复制 `templates/MANUAL_SCORE_SHEET.md`，填入 case id、plan file、report dir、每项得分。统一 100 分制：

- 90-100: PASS, 可展示。
- 75-89: WARN, 能用但有明显优化点。
- 50-74: WEAK, 产物存在但科学/交互/执行路径不可靠。
- 0-49: BLOCK, 假成功、崩溃、无报告、schema 错误或严重 unsupported claims。

## 5. 结束后保留证据

至少保留：

- `plans/<timestamp>.md`
- `reports/<timestamp>/`
- REPL transcript 或关键截图/复制文本。
- 评分表。
