# Report Checklist

Apply this to any case that produces `generate_report(format="dual")`.

## Required Files

```text
report.md
report_technical.md
report_nature.md
_report_with_css.md
_report_nature_with_css.md
report.html
report_nature.html
```

## Technical Report Must Include

- Executive findings near the top.
- Study status or equivalent summary table.
- Cohort counts and endpoint definition.
- Model selection section when `train_model(model_type="auto")` ran.
- Evaluation/calibration/feature importance sections when applicable.
- Statistical review and safety/governance caveats.
- Execution appendix separated from human-facing interpretation.

## Nature-Style Report Must Include

- Abstract.
- Introduction or study rationale.
- Methods.
- Results.
- Discussion.
- Limitations.
- Data availability/governance statement.
- References or explicit note that literature records were unavailable.

## Must Not Include

- `Generated by:`, author/institution placeholders, AI tool branding, raw stdout/stderr.
- `TODO`, `[CITATION_NEEDED]`, `references to be added`.
- Patient-level IDs or rows.
- Unsupported claims like "causal proof", "clinically deployable", "validated forecast" without explicit supporting evidence.

## Table and Figure Checks

- Markdown tables should be contiguous with no blank lines inside table blocks.
- SVG/PNG figures should be embedded with markdown image links when referenced.
- Relative figure paths must resolve from the report directory.
- Figures should have interpretable captions, not only file names.
