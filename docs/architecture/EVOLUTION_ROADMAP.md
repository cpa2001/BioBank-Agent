## 1. North Star

biobank-agent becomes a **trustworthy scientific instrument, not a chatbot**: every claim it makes is
grounded in data it actually inspected, every "done" is bound to a real, schema-valid, re-runnable
artifact, and every result passes a methodological-soundness gate before it can be called a finding. It
is a **self-improving control loop** — verified trajectories distill into lazily-loaded,
regression-gated skills so each solved task makes the next cheaper, safer, and more likely to succeed —
and it runs the *actual* genomics workloads (hour-scale jobs, HPC schedulers) the science demands.

## 2. Design Principles (first-principles tenets)

1. **Trust economics dominate cleverness.** A fabricated p-value or an invisible "done" loses the
   scientist forever; latency is forgiven. Optimize for *verifiable* outcomes before *clever* ones.
2. **Verifiable autonomy.** Autonomy is only granted behind a gate that proves the outcome. No step is
   "done" without a real artifact; no skill auto-merges without a *mutation-checked* test; no
   statistical claim survives without a methodology check.
3. **Evidence precedes learning.** The self-evolution flywheel may only mine trajectories whose steps
   passed the Evidence Contract. Learning from a hallucinated success compounds the worst thing.
4. **Context frugality as a tax cut.** A bloated tool list is a silent tax on *every* turn. Bounded
   fragments + lazy skill exposure make corpus growth free at the context level.
5. **Reuse the hardened core; wire, don't rebuild.** The transactional apply loop, the council, the
   harness, the 8-tier memory already exist and are good. Most initiatives are *connectors*.
6. **Method contracts over return codes.** Scientific correctness ≠ exit 0. Skills declare pre/post
   scientific conditions; the verifier enforces them.
7. **The substrate must produce real trajectories.** A learning loop with no real genomics jobs to
   learn from spins on toy data. The execution backend is foundational, not a UX nicety.
8. **Archive, never delete; pin to protect.** Self-evolution touches only agent-created, unpinned
   skills. User trust in `/skills` as a stable interface is sacrosanct.

## 4. Architecture Roadmap (phased)

**Binding reframings from the debate:**
- **BLOCKER 1:** Self-evolution auto-merge must be gated behind *both* the Evidence Contract *and* the
  Methodological reviewer *and* the mutation check. → Self-evolution is **Later-gated**, not Now.
- **BLOCKER 2:** No persona scoped a scheduler/cluster execution backend; on an HPC login node the
  scientist `sbatch`/`dx run`s a GWAS. Without it the flywheel has no real trajectories. → **Now/Next.**

### NOW — the trust floor + the substrate that generates trajectories
- **N1 Artifact & Evidence Contract** (M) — bind step "done" to a real, schema-aware observed artifact
  satisfying the step's declared `verification`; else `unverified`, never `done`. Exemption derived from
  *absence of declared verification*, not a self-assigned `step.kind` label.
- **N2 Data-grounded planning (DataProbe)** (M→L) — read-only probe of every referenced file/dataset
  *before* the council drafts; inject a bounded `DataContext` (≤800 tok) with typed `probe_confidence`.
  Kills the CSV→WGS misroute at the root. Local tabular files only; degrade loudly on HPC/Spark paths.
- **N3 Lazy skill exposure** (M) — ~12-15 Direct skills + 8 node summaries injected; the rest via a
  `skill_search` tool (BM25 over name+description). `skills/manifest.json` overlay; `check_fn` gates
  hide `vcf_*` when no genotype is in scope. Fund for cost/cache/scaling only.
- **N4 Methodological-soundness reviewer** (M) — in the verification mesh; hard-block consensus
  statistical sins (uncorrected multiple testing, n-below-power, missing CIs, unaddressed
  stratification). *First target: fix `vcf_association` to consume `vcf_pca` PCs as covariates — verified
  live bug (writes only age/sex yet warns the user to add PCA correction).*
- **N5 Streaming + scheduler-aware execution backend** (L) — pluggable `EnvironmentBackend` (local
  streaming + Slurm/SGE/LSF/`dx run`); bounded buffering, heartbeats, `TOOL_PROGRESS` deltas to UI.
  *(Local streaming substrate already landed: `runtime/proc.py` + `runtime/jobs.py`.)*

### NEXT — reliability + recoverability for long autonomous runs
- **X1 Robust council** (M) — JSON-repair retry + deterministic labeled scaffold-plan fallback; feed the
  planner the clustered tool menu from N3 instead of a flat `tools[:80]`.
- **X2 Execution-time council escalation** (M) — when the loop guard fires, a 2-model 1-round debate
  decides the change-of-approach (reuses existing `run_parallel`), gated behind the loop guard + budget.
- **X3 Durable append-only rollout + resume-at-step** (M) — one event per line + SQLite cursor; re-entered
  plan restarts at the last *completed* step; importer for legacy `session.json`.
- **X4 Reproducibility receipt** (L) — per artifact: tool calls+args, DataContext fingerprint (hash +
  schema + rowcount), skill versions, model roles, the verification that passed → `reports/<session>/
  receipt.{json,md}`. Covers verified NULL results as first-class citable outputs.

### LATER — the compounding self-evolution flywheel (gated behind the trust floor)
- **L1 Close the self-evolution loop** (M) — LLM reflection over *evidence-backed* trajectories emits
  concrete `{target_path, diff, test_commands}` through the existing hardened `apply_patch_transactionally`,
  **with a mutation check** (PASS-with-diff, FAIL-on-revert). Review-branch for analysis logic; auto-merge
  only net-new, fully-tested, allow-listed, methodology-passing skills.
- **L2 Inactivity-triggered curator** (M) — auxiliary session; archives unused agent-created skills
  (active→stale→archived, never delete), consolidates duplicates, re-tiers by usage. Only
  `is_agent_created && !pinned`.
- **L3 Discovery → skill promotion + auto-grown harness** (L) — verified ≥2-support patterns become
  skills *and* `HarnessTask` regression cases wired into scheduled-eval CI. Mines evidence-backed
  trajectories ONLY.
- **L4 DAAO routing fed verified outcomes** (S) — call `difficulty.record_outcome` with verified triples.
- **L5 Skill-from-papers acquisition** (L) — `deep_research`/`replicate_paper`/`read_paper` feed a
  method-extraction pass proposing a skill *with its method contract*, routed through L1's gate.

## 5. Self-Evolution & Intelligence Engine

The loop is *open* today for four fixable-as-wiring reasons: (a) proposals are prose with no diff/tests
(`evolution.py:_proposal_shape` 220-244); (b) the hardened apply loop is starved of real patches; (c)
no trigger / auxiliary executor; (d) **no quality gate on which trajectories are worth learning from**.

**Closed loop** (stage → existing code + connector): SENSE (usage counter in `invoke_tool` → manifest)
→ JUDGE (per-step Evidence Contract N1 + Methodology reviewer N4 under existing `verdict`/`guardrails`/
`verifier_mesh`/Z3; a success with no artifact is invisible to learning) → MINE (`pattern_mining` over
≥2-support successes; `reflexion` over failures into 8-tier memory) → PROPOSE (`EvolutionProposal` with
`target_path`+`diff`+`test_commands`) → GATE (existing `apply_patch_transactionally`: worktree, per-file
path re-validation, PROTECTED_PREFIXES, hardened anti-laundering — **do NOT weaken**) → MUTATION CHECK
(close the vacuous-test hole) → METHODOLOGY GATE (N4 in the apply path) → PROMOTE & REGRESS (applied skill
→ `HarnessTask` → scheduled-eval CI) → CURATE (idle, aux cache, archive-only, agent-created-only).

**Three durable accumulators:** procedural memory (curated skill library), episodic/semantic memory
(reflexion + evidence chains in 8-tier `memory.py`), eval corpus (self-manufactured regression cases →
"better" becomes measurable, drift detectable).

**Safety contract** (surfaced via `/evolve status`): default review-branch for analysis logic;
auto-merge only net-new + fully-tested + mutation-checked + methodology-passing + allow-listed +
unprotected; only agent-created/unpinned curated; archive-never-delete; curator on auxiliary model only;
behind a config flag defaulting conservative; NULL results are first-class.

## 6. Skill-Tree Taxonomy

**Problem (verified):** 81 skills in a FLAT `biobank_agent/skills/*.py`; `engine.py` dumps all 81 schemas
into *every* `run_turn`; `planner.py` sends `tools[:80]` flat. The registry already does AST lazy-*import*
— the missing layer is **organization + exposure tiers**, not new loading code.

**The tree is METADATA, not a filesystem move.** Ship `skills/manifest.json` (additive) carrying per-skill
`domain`, `exposure` (Direct/Deferred/Hidden), `trust` (core/curated/agent), `agent_created`, `pinned`,
`last_used`, `use_count`, `consolidation_id`. Tag in the manifest first; regroup files opportunistically.

```
CORE / WORKSPACE        [Direct, ~12-15, maintainer-owned, curator-immutable]
  shell_exec, python_exec, read, write, edit, grep, apply_patch, test,
  data_query, ukb_full_data, vcf_query
DATA ACCESS & SHAPING   [Direct gateways / Deferred specifics]
  bank_data_probe, bank_data_readiness, cohort_*, phenotype_harmonize, missing_data, prevalence
GENOMICS / VARIANTS     [Deferred; check_fn-gated on a genotype file in DataContext]
  vcf_qc, vcf_annotation, vcf_association, vcf_burden_test, vcf_kinship, vcf_pca,
  vcf_phenotype_compare, gwas_proxy, genetic_target_hypothesis, target_*
STATISTICS & MODELING   [Deferred]
  correlation, comorbidity, survival, phewas, biomarker_dist, feature_importance, calibration,
  min_sample, predict, train_model, train_phenotype_model, evaluate_model, embedding
METHODOLOGY & REVIEW    [Direct — credibility gate, feeds N4]
  statistical_review, critical_thinking, safety_check, calibration
LITERATURE & HYPOTHESIS [Deferred]
  deep_research, literature_qa, fetch_paper, read_paper, read_pdf, web_search, web_fetch,
  hypothesis, brainstorm, discovery, replicate_paper, paper_replication_compare
REPORTING & NARRATIVE   [Deferred]
  report, smart_plot, cohort_card, academic_report_polisher, nature_writer, project_doc
TRAJECTORY / META / SELF [Hidden — runtime/curator-invoked, not LLM-callable]
  trajectory_profile, trajectory_tokenize, record_macro, replay_pipeline, create_skill,
  agent_workflow_evolver, recall_session, track_error, retry, environment_repair,
  error_suggestions, clarification_policy, goal_intent_classifier
SPECIALIZED / ONE-OFF   [Hidden — curator's first archive candidates]
  juvenile_hair_mechanism, virtualcell_multimodal, ...
```

**Exposure mechanics:** inject ~12-15 Direct + 8 one-line node summaries; Deferred surface via
`skill_search` (BM25); `check_fn` hides irrelevant domains. **Per-turn skill context ~81 → ~15.**

**Registry changes (`registry.py`):** add `category`/`exposure`/`check_fn` to `@skill`; load
`manifest.json` (default unlisted = Deferred); `tool_schemas()`/`list_handlers()` gain a `tier=` filter;
invalidate BM25 on `create_skill` hot-reload; `/skills` renders the full tree with tiers + usage +
`agent_created`/`pinned` badges.

**Top NEW skills from papers:** PCs-as-covariates GWAS (fix `vcf_association`) · multiple-testing-corrected
PheWAS · power/sample-size pre-check (wraps `min_sample`) · published-pipeline replication (L5) ·
mixed-model association (for related/structured cohorts).

## 8. Risks & Open Questions

**Top risks:** (1) self-evolution merging unsound/vacuous skills → hard-gate M8/M9 behind M2+M3 +
mutation check; (2) DataProbe coverage on HPC/dxfuse/Spark → typed `probe_confidence` + loud
degradation, scope = local tabular only; (3) Evidence Contract exemption loophole → derive from absence
of declared verification; (4) mis-tiered critical skill invisible → usage-driven promotion + full-tree
`/skills`; (5) learning N too small for RL → defer outcome-reward/credit-assignment until receipts +
harness accumulate a corpus.

**Open (need a decision):**
- **Data-governance / consent-scope** — UKB/CKB run under per-project field allow-lists. Recommend a
  `consent_scope` config enforced in `data_query`/`ukb_full_data` + a consent fingerprint in the receipt.
  Schedule between M3 and M7. *(needs product/ethics input.)*
- **Cost/compute budget governor** — per-session spend cap + global daily ceiling wherever the
  council/curator spawns. Add before M9 (overnight autonomous runs).
- **Multi-tenant concurrency** — `self_evolve` worktree, `SessionStore`, `manifest.json` assume a single
  writer. Recommend manifest file-locking + per-user receipt namespacing before any shared-install.

**Framework migration — RECOMMENDATION: keep the custom runtime; borrow patterns, do NOT migrate.**
LangGraph (graph/checkpointer/conditional edges) maps onto what exists (council, ReAct loop, harness +
replay); migrating discards the verified hardened apply loop + council + 8-tier memory for marginal
structural gain — borrow its conditional-edge escalation idea (M5/X2) without the framework. Temporal
solves durable execution at a scale a single-machine local-first agent doesn't need; the append-only
JSONL rollout + SQLite cursor (M6) gives 90% of the durability at 5% of the operational cost. OpenCode's
Effect-TS Source/Layer/Coordinator concepts are excellent but TS-native — borrow the *ideas* (bounded
fragments, coalesced resume) in idiomatic Python. The hardest parts already exist and are good; the
roadmap is overwhelmingly *wiring + bounded new modules*.
